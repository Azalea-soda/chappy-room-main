# チャッピー（現行開発リポジトリ）

このリポジトリは、チャッピーアプリの**現在の開発対象**です。

## どのリポジトリを編集する？

- **現在の開発対象：このリポジトリ `Azalea-soda/chappy-room-main`**
- **旧版の参照先：`Azalea-soda/chappy-room-archive`**
  - 旧版の確認用です。通常の開発・修正には使用しないでください。

迷ったときは、リポジトリ名だけで判断せず、このREADMEと現在の作業指示を確認してください。

## ブランチの扱い

- `main`：このリポジトリの既定ブランチです。アプリ本体の現行コードを管理します。
- `memory-admin-v1`：記憶管理画面・管理用Workerのテスト開発ブランチです。テスト環境向けの作業に使用します。
- その他のブランチ：それぞれの作業目的を確認してから使用してください。

**テスト用の変更を、確認なしに `main` へマージ・反映しないでください。**

## 大切な注意

- 旧版リポジトリを現行版として編集しないでください。
- 本番用Cloudflare Workerや本番D1データベースを、明示的な承認なしに変更しないでください。
- D1の接続先・認証情報・デプロイ先を変更する前に、対象環境を必ず確認してください。
- 画面デザインや既存動作を変更する場合は、現在の仕様と作業指示を確認してください。

## このプロジェクトについて

チャッピーは、お母さんとの日々の会話を支え、声のリハビリにも役立てることを目指すアプリです。安全性・プライバシー・使いやすさを大切にしながら開発します。
